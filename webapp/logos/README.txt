Product logo images go here (used by the Mini App storefront).

For each product, put an image file in this folder (square works best, e.g.
120x120 PNG) and write its filename in the product's "Logo" column (M) in the
Products sheet — for example:  netflix.png

Rules:
- The filename in the sheet must match the file here exactly (case-sensitive).
- You can instead put a full https:// image URL in the Logo column; then no
  file is needed here.
- If a product has no Logo, the Mini App falls back to its Icon emoji (column K).

These files are deployed together with index.html.
